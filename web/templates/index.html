Buffer Analysis Guide

Goal: Find the correct texture indices for RGB, Normal, and Depth in your game's .rdc capture.

1. Open .rdc in RenderDoc

File → Open Capture → select your .rdc file. Or use Tools → Analyze Capture File (automated).

2. Open the Texture Viewer

Click Texture Viewer tab. The resource list on the left shows all textures used in that frame.

3. Find the RGB (backbuffer)

Look for a texture matching render resolution. Usually the last ColorTarget with R8G8B8A8 or B8G8R8A8 format. The texture index shown in the resource list is the number to use as rgb_index.

4. Find the Depth buffer

Filter by DepthTarget in the resource panel. Format is typically D24S8 or D32F. Note the index for depth_index. UE3/standard depth: depth_reversed_z: false. UE5: true.

5. Find the Normal buffer (GBuffer)

UE5: look for R10G10B10A2 format — that's GBufferA (WorldNormal). UE3: may be a separate R8G8B8A8 render target. Browse render targets and look for one that visually shows surface normals (rainbow colors from different angles).

6. Record indices

The index is the number in brackets in the resource list (0-based). Use Tools → Capture Config to see current settings, then ask the AI to update configs/hacks/<game_id>.json with the correct values.

Shortcut: use Tools → Analyze Capture File to run automated export and see all ct_*.png thumbnails side by side.
